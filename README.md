## Overview
 
The **Small Business Inventory Management System** is designed to support the daily operations of **Coffee Trail**, a coffee shop business. This system is not only limited to monitoring inventory levels — it is developed as a comprehensive tool that can be used in everyday business activities.

---
 
## Features
 
### 📦 Inventory Tracking
Efficiently track and manage inventory, ensuring that stock levels are always updated and accurate in real time.
 
### 🧾 Customer Order Processing
Records customer orders and sales transactions. Each time a customer purchases a product, the system automatically deducts the corresponding quantity from the inventory, ensuring real-time and accurate stock updates.
 
### 📊 Sales Recording
Tracks daily transactions, monitors revenue, and enables analysis of sales performance over time.
 
### 🔒 User Activity Logs
Maintains user logs to record system activity, ensuring accountability and security among users.
 
---
 
## Purpose
 
The main purpose of this system is to **improve efficiency**, **reduce manual errors**, and **streamline business processes** within the coffee shop. By integrating inventory management, customer order processing (de-stocking), sales tracking, and user activity monitoring into a single system, Coffee Trail can operate more effectively and make better-informed business decisions.
